# Prefix D

ブラウザ向け3Dドライビングゲーム「Prefix D」（個人開発）。
自分で運転して街を走るほか、タイムアタック・NPC対戦・オンラインで友だちと走れる。

- 遊ぶ: https://shuheikomatsuki.github.io/prefix-d/
- 設計提案: [docs/design-proposal.md](docs/design-proposal.md)

## 遊び方

### 画面の流れ

起動するとタイトル画面から始まる。どれかのキーを押す（スマホはタップ）とトップメニューになり、プレイモード（自由に走る・タイムアタック・NPCと対戦・ライバルとバトル・オンライン）を選んで、コース・対戦相手・ルール・自分の車・時間帯と天気を1画面ずつ選び、最後に「スタート」。左に一覧、右に選んでいるものの詳しい説明が出る（コースは上から見た形・高低差のグラフ・全長・最大勾配・道幅・おすすめの車、車は回る車の見た目と性能、ライバルは写真・ひとこと紹介・強さ・マシン）。走っている間は `Esc`（スマホは ☰）でメニュー画面を開き、「タイトルに戻る」で最初のタイトル画面へ戻れる。スマホは ☰ をもう一度押すと走りに戻る。レース中はメニュー画面の「コース・車などを変える」とゴールの画面の「コース・車など」で、同じモードのまま、そのモードの選ぶ画面（ライバルとバトルなら対戦相手・ルール・コース・車・時間帯と天気、NPCと対戦なら NPC の強さも）をもう一度たどって選び直せる。どの画面もいまの内容が選ばれた状態で始まるので、変えたいところだけ変えればよい（タイトルに戻らなくてよい）。自由に走っている間も、メニュー画面の「コース・車などを変える」でコース・車・時間帯と天気を選び直せる。タイトル画面の後ろには、峠・首都高のどれか（毎回変わる。練習用のコースと、作るのに時間のかかる超ロング・八方ヶ原・いろは坂は除く）が映る。`?map=3` のようにマップを指定して開いたときは、タイトルを飛ばしてすぐ走れる。

### 運転

| キー | ゲームパッド | 操作 |
|---|---|---|
| `W` / `↑` | RT（または A） | アクセル |
| `S` / `↓` / `Space` | LT | ブレーキ（停止中に押し続けると後退） |
| `A` `D` / `←` `→` | 左スティック | ハンドル |

キーボードのハンドルは、軽く叩くと少しだけ切れ、押し続けるほど深く切れる（0.25秒で目いっぱい）。細かい修正がしやすい。☰ メニューの設定「キーのハンドル: すぐ全開」にすると、押した瞬間から目いっぱい切る（`src/core/input.ts`）。

### タイムアタック

`T`（またはトップメニューの「タイムアタック」）で、スタートラインの手前に並ぶ。アクセルを踏むとカウントダウンが始まり、タイムを計る（自分のタイミングでスタートできる）。レース用のマップにいればそのコース、それ以外なら首都高へ移動する。走っている間は `N` でコースを替えられる。

| コース | 内容 |
|---|---|
| 首都高（都心環状線） | 都心環状線のようなオリジナルの首都高（一周 約4.5km）。実際の道の形のデータは使わず、名所の並び（内回り）をなぞった。高架の2車線で両側は壁。長い直線はなく、京橋から日本橋川の上へ出て江戸橋 JCT のきつい左、神田橋〜竹橋の S 字、北の丸の下の千代田トンネル、三宅坂〜霞が関の中速コーナー、谷町 JCT のきつい左、一ノ橋〜芝公園、浜崎橋 JCT のきつい左と汐留の S 字を通って京橋に戻る。1周 |
| 峠（ヒルクライム） | ふもとから頂上まで 150m 上る一本道（約2km）。半径 150m の高速コーナー、S 字、3つのヘアピンが混じる。坂で加速が鈍る |
| 峠（ダウンヒル） | 同じ峠を頂上から下る。スピードが乗るので早めのブレーキが大事 |
| 峠（山越え） | 100m あまり上って峠を越え、反対側へ下る（約2.1km）。頂上は見通しのよい高速の左右 |
| 峠（Uターン） | 谷沿いに上り、頂上のヘアピンで折り返して 38m 横を並んで下る（約2.2km）。行きの高速コーナーは帰りの低速コーナーになる。ゴールはスタートのそば |
| いろは坂（ヒルクライム） | 第二いろは坂（上り専用・約9.4km・高低差 440m・20 カーブ）。馬返から、谷沿いの緩い上りの高速区間を抜け、斜面に取り付いて 12 個のヘアピンを積み重ねて上り（ヘアピンの間も、ヘアピンのすぐ前後の短い直線のほかは左右にうねり続けるスネークヘアピン。木が道路のすぐ脇まで茂り、山側は道路のすぐ脇から岩の崖が立っていて見通しが悪い）、明智平の先のトンネルを抜けて中禅寺湖のそばの頂上へ。2 車線の一方通行で道幅は広い。上りも下りも、実際の道の形のデータではなく、全長・カーブの数・高低差と区間の並びを実際に合わせている |
| いろは坂（ダウンヒル） | 第一いろは坂（下り専用・約6.5km・高低差 440m・28 カーブ）。頂上の剣ヶ峰付近の中速の左右から、上側のつづら折り（ヘアピン 9 個）、斜面のトラバース、下側のつづら折り（ヘアピン 8 個）を下って馬返へ。ヘアピンの間も、ヘアピンのすぐ前後の短い直線のほかは左右にうねり続けるスネークヘアピン。木が道路のすぐ脇まで茂り、山側（すぐ上を一つ前の区間が通る側）は道路のすぐ脇から山を切り開いた岩の崖が立っていて見通しが悪い。崖にはぶつかる（落ちない）。馬返の手前の最後は、谷を橋で渡る。ヘアピンの内側を突っ切って、段差から下の道路へ飛び降りる近道（下記）がある |
| 激坂（ヒルクライム） | 約1.4km で 230m 上る急坂（平均 17%）。きついヘアピンが 3 つ。パワーのない車は伸びなくなる |
| 激坂（ダウンヒル） | 同じ激坂を下る。ブレーキが遅れるとコーナーで止まりきれない |
| 峠（ロング） | 上りと下りを何度もくり返す約2.9kmの長いコース。高速コーナーとヘアピンが交互に来る |
| 峠（超ロング） | 上りと下りをくり返す約6.2kmのいちばん長いコース |
| ロングストレート（ヒルクライム / ダウンヒル） | 峠の途中に、まっすぐな 800m のロングストレートと、ごく僅かに左右へくねる 650m のロングストレートがある。前後と間はふつうの峠のコーナー（約2.9km、高低差 170m） |
| 橋とトンネルの峠（ヒルクライム / ダウンヒル） | 約4.8km の峠。コーナーの続く区間の途中で 3 回谷を橋で渡り、短いトンネル（90m）と長いトンネル（360m）を抜ける（高低差 230m） |
| 八方ヶ原風の峠（往復） | 4つのセクションに分かれた峠（道路 3.5km）を往復する（約6.8km）。第1は道幅が狭く木が茂って見通しの悪い古い道、第2は拡幅工事を終えた新設の広い道（真新しい舗装と白線、両側に白いガードレール、削った山の斜面は吹き付けたばかりのコンクリート）だが、路面が荒れていて車が跳ねる。ハイポイントコーナーの先の第3はきついダウンヒルで、高さ 55m の谷に架かる大きな橋を渡ると、第4はきついヒルクライム（道幅 10m で、追い抜きやすい）。330° 回り込むループ橋、カーブの途中の 240m のトンネルを抜け、上り切った先の平らな道を少し走って頂上の広場で U ターンし、同じ道を戻ってきてスタートラインがゴール |
| 秋名（ダウンヒル） | 秋名（榛名山）のダウンヒル（約4.3km・高低差 330m）。実際の道の形のデータではなく、原作・アニメ・アーケードで知られる区間の並びを再現: 緩い下りから中速の左右、長い下りのストレートの先の最初のヘアピン、連続コーナー、スケートセンター前のいちばん長い直線、左右交互の5連続ヘアピン、S字、最後の直線。ヘアピンなどのカーブの内側の路肩には側溝があり、内側のタイヤを落とす（車体の中心を道路の端から 0.2〜0.8m 内側まで寄せる）と溝の壁に引っかかって、横に滑らずに曲がれる力が 4割増える（溝落とし。車体が内側に傾いてゴトゴト揺れる）。コースは `src/map/maps.ts` の `AKINA_DOWN_MAP`、溝は `RoadPiece.gutter` |

- 走っている間は、これまでの周回タイム（自己ベストの同じ周との差）と、右上に地図（自分は赤、ゴーストは水色）を出す。地図は自由に走る・オンラインの部屋でも出る（街・教習所は道路のつながりを描く。部屋の他の人の位置も出る）。地図の出し方は設定の「マップ」で選ぶ: 周辺・回転（最初はこれ。アーケードのように自分の周り 460m 四方だけを、進む向きが上になるよう回して出す。自分は少し下寄りで前が広く見える）／周辺・北が上（回さずに自分を真ん中に）／全体（コース全体）。
- 峠の高低差は見た目と坂の重力だけで、衝突の計算は平らなまま（`src/map/terrain.ts`）。
- いろは坂（ダウンヒル）では、ヘアピンの内側（行きと帰りの道路にはさまれた所）がコンクリートの面になっている（いろは坂の「インベタのさらにインベタ」）。コーナーの手前で内側へ飛び込めば、道路よりずっと小さく回れる。面は上の道路の高さから下っていき、下の道路の縁で段差（最大 2.5m）になって終わるので、段差から飛び降りると真下が下の道路。面の上は落ちず、コースアウトにもならない（周回も進む）。浮いている間はハンドルもアクセルも効かないので、向きを決めてから飛ぶ。面の外側は崖（`src/map/roadShortcuts.ts`。180° の円弧の前後が直線のヘアピンを探して帯を作る）。
- 峠では、道路の外は少しの路肩の先が崖（岩肌の色の斜面）になっている。路肩より外へ出ると「コースアウト！」と出て落ち、1 秒ほどで落ちた地点の少し手前に止まった状態で戻される（その間もタイムは進む）。カーブの外側にはガードレールがある。NPC も同じ。
- 峠の橋は深い谷（底に川）に架かり、トンネルは山の中を抜ける。橋の上とトンネルの中は両側が壁で、落ちることはない。地図の記号は `=`（橋）・`~`（川）・`#`（トンネル）。
- 練習用の小さな街と教習所コースを除くすべてのコースは、タイルではなく直線と円弧をつないだ中心線で道路を描く（`src/map/road.ts`）。タイルのコースのように「90° 曲がって直線」をくり返すのではなく、半径（大きいほど速く回れる）と曲がる角度を区間ごとに決めるので、半径 200m の高速コーナーから半径 16m のヘアピンまで、なめらかな円のカーブになる。周回のコースは最後の直線・円弧・直線を計算して始まりにつなぎ（`closeLoop`）、ダウンヒルは上りの道路を逆向きにたどる（`reverseRoad`）。峠（Uターン）の帰り道は、行きの道を横へずらした道を逆向きにたどる（`alongside`。内側になるカーブは半径が小さくなる）。区間ごとに高さ・道幅・橋・トンネル・荒れた路面を指定でき、道路が自分の上を越える立体交差も作れる。衝突の計算は平らなままなので、立体交差では上の道路と下の道路の壁を別の層に分け、車はいま走っている道の層の壁と車にだけぶつかる。どちらの道にいるかは、直前にいたコース上の位置から近くだけを探して追う（`src/race/roadCourse.ts`）。往復のコースでも、行きと帰りを向きで見分ける。
- 荒れた路面は、舗装全体がゆるく波打っている（継ぎ目だけの段差ではない）。波の高さは ±3.5cm、長さ 14m と 30m の波を重ねてあり、180km/h くらいまでは揺すられるだけだが、それより速いと波の頂上で少し浮く（浮いている間はタイヤが効かない）。

- コースのタイル（中心線で描く道路では 10m ごとの区間）を順にたどった場合だけ周回に数える。コースを外れて先へ近道すると「近道はできません」と出て、1.2 秒後にコースを外れた所へ自動で戻される（どこまで戻ればよいか迷わないように）。逆向きに走ると「逆走しています」と出る。
- 自己ベスト（3 周の合計と最速ラップ）は、コースと車の組み合わせごとにブラウザ内（localStorage）に保存する。コースはコースの id と「形の版」（コースの定義から作る短い英数字。`src/map/courseRevision.ts`）で区別し、コースの形を直すと前の形で走った自己ベスト・ゴーストは使われなくなる（ランキングも形の版ごとに別になる）。名前や標識を変えただけなら版は変わらない。道路の作り方のコードを変えてコースの形が変わったときは `COURSE_BUILDER_VERSION` を上げる。設定の「プレイデータを消す」で、自己ベスト・ゴースト・勝ったライバルの記録を消せる（確認の画面で「消す」を選んだときだけ消す。名前などの設定とランキングの記録は残る）。
- ブラウザに残すデータには版（`car-game:save-version`）をつけ、起動のたびに古い版のデータを今の版の形に直す（`src/game/saveVersion.ts`）。データの形を変えるときは版を上げて、直す手順を足す。あとから車を手に入れる仕組みを作るなら、持っている車を一覧で保存し、一覧にない車は使えないことにすれば、今までのデータには一覧がないので最初の車だけになる。ただしブラウザのデータは本人が書き換えられるので、確実に防ぐにはサーバーで持つ。
- 自己ベストの走りは、半透明の水色の車（ゴースト）として一緒に走る。
- `R` でスタートからやり直し、もう一度 `T` でやめる。

### ランキング（ゴーストと対戦）

`L`（スマホは ☰ メニューの「ランキング」）で、コースごとのランキング（上位 20 件）を、順位・名前・車・タイム・日付（年月日）の列で出す（表の上に列の名前）。左のコースの一覧（縦向きのスマホでは横に並ぶ札）でコースを、上の車の札で車を選ぶ。最初は「すべての車」の記録をまとめて出し、車を選ぶとその車だけのランキングになる。オンライン用のサーバーを使う。

- 名前は 10 文字まで（オンラインの部屋での名前と同じ）。名前を入れておくと、タイムアタックでゴールしたとき自己ベストが走り（ゴースト）と一緒に自動で送られ、結果に順位が出る。名前を入れる前に出した自己ベストも、ランキングを開いたときに送られる。
- 記録はコースと車の組み合わせごとに、1人につき一番速いものだけが残る（同じブラウザを同じ人とみなす。ブラウザごとに作る秘密の id で見分ける）。「すべての車」では、同じ人でも車が違えば別の行になる。
- 「対戦」を押すと、その人のゴースト（オレンジ色、名前付き）とそのコース・車でタイムアタックする。自分の自己ベストのゴースト（水色）も一緒に走る。
- 「リプレイ」を押すと、その人の走りをリプレイで見られる（下の「リプレイ」）。同じ車の自分の自己ベストがあれば、半透明の水色で並べて走らせる。閉じるとランキングの画面に戻る。
- 友だちと遊ぶ前提なので、偽のタイムを防ぐ仕組みはない。

### リプレイ

タイムアタック・NPC 対戦・ライバルとのバトルでゴールすると、結果の「リプレイ」（`V`）で走りを見返せる。ランキングの「リプレイ」では、他の人の走りも見られる。

- 走りは、自分と NPC・ライバルの車ごとに 0.1 秒おきに、位置と向きに加えて操作（タイヤの切れ角・アクセル・ブレーキ・速さ・アンダーステアの度合い）を記録する（`src/race/ghost.ts` の `GhostRecorder`、`src/race/replay.ts`）。全員ゴールして 2 秒経つまで（NPC が遅ければ自分のゴールから 30 秒まで）記録する。タイムアタックでは、一緒に走った自己ベスト・ランキングの人のゴーストも半透明で出す。
- 画面の左下に、追いかけている車の速さ・ハンドル（絵と「左 35%」のような切れ角。いっぱいに切ったときが 100%）・アクセルとブレーキの踏み具合（左がブレーキ、右がアクセル）と、前 6 秒・後 2 秒のグラフ（上がハンドルで上が左、その下にアクセル・ブレーキ。アンダーステアの所はオレンジ）を出す。
- 下のバーは走り全体のアクセル（緑）・ブレーキ（赤）と、周回・ゴールの目印。触れた所・ドラッグした所へ飛ぶ。
- カメラ（`C`）は運転中と同じ視点（三人称 近／遠・運転席）のあとに、リプレイだけの TV中継（車が来る所の脇に置いたカメラが首を振って追い、通り過ぎたら次のカメラへ切り替える）・横から・前から・上空 の順に替わる（`src/render/replayCamera.ts`）。
- キー: `Space` 再生・一時停止、`←` `→` 5 秒戻る・進む（`Shift` で 1 秒）、`,` `.` 0.1 秒ずつ、`↑` `↓` 再生の速さ（×0.25〜×4）、`V`（`Tab`）追いかける車を替える、`C` カメラ、`Esc` 終わる。スマホは画面のボタンで操作する。
- 自己ベストとランキングの記録にも操作を付けて保存・送信する（ランキングのサーバーは `inputs:<記録の id>` に保存）。操作を記録する前の記録は、位置と速さだけを見せる。
- リプレイを見ている間は、レースと車は止まっている（終わると結果の画面に戻る）。オンライン対戦はみんなと走っているので、リプレイは出さない。

コースと車は、表示名ではなく変わらない id（`src/map/maps.ts` の `id`、`src/sim/vehicle.ts` の `VEHICLE_PRESETS` の `id`）でランキングを分けている。表示名は自由に変えてよい（例: 「普通車」を具体的な車名にしても、id が `standard` のままならランキングはそのまま）。車の性能を大きく変えるなら、新しい id にすると新しいランキングになる（古いランキングはどこからも開かれなくなるだけで、消さなくても困らない）。

### NPC対戦

`Y`（スマホは ☰ メニューの「NPCと対戦」）で、タイムアタックと同じコースを NPC 3台と走る。NPC が前に並び、自分は最後尾からスタートする。NPC の並び順（どの色の車がどこに並ぶか）は毎回ランダム。

- NPC の強さは `K`（スマホはメニュー）で 初級／中級／上級／超上級 を選ぶ（`?npc=legend` のように URL でも指定できる。id は easy / normal / hard / legend）。強いほど理想のライン（レーシングライン）を正確になぞり、カーブとブレーキで車の限界近くまで使う。超上級は車の性能をほぼ使い切る。ひとりで走ったタイムは、超上級に比べて上級が約2〜4%、中級が約5〜8%、初級が約11〜17% 遅い。
- NPC は自分と同じ車種・同じ物理で走る。前の車に追いつくと横に出て抜き、抜けないときは速度を合わせる。ぶつかれば押し合う。上級以上は、後ろ 12m 以内に車がいるとき次のコーナーの内側へ寄せてインを閉める（抜くにはブレーキングか立ち上がりで勝つ）。
- 壁や他の車とこすれると、押し戻された強さに応じて摩擦で速度を失う（`src/sim/car.ts` の `CONTACT_FRICTION`）。壁に押し付けて曲がったり、NPC にぶつけてインをこじ開けたりすると、そのぶん遅くなる。
- 走っている間は順位を出し、ゴールすると順位表を出す（まだ走っている NPC がゴールするたびに更新する）。自分がまだ走っている間に NPC・ライバルがゴールすると、画面の真ん中に「〇〇 がゴール 1位 2:13.45」のように少しの間出る。NPC 対戦の結果は自己ベストには残さない。

- 最高速は、イニシャルDのアニメの場面（メーターの読み・直線での伸び・車どうしの差）と、それぞれの車のチューニングから見積もった値。アクセルを踏み続けると、平らな直線でこの速さに落ち着く（エンジンの加速と空気抵抗が釣り合う速さ）。
- 加速は、実車の 0-100km/h・0-400m の計測（AE86 約8.5秒、FD3S 約5秒台、R34 約5秒など）に、作中のチューニングを少し足した値に合わせた。低速ではタイヤのグリップ（1速で出せる加速）で、速くなると出力（出力 ÷ 速さ）で決まるので、高速になるほど伸びが鈍る。
- ブレーキとコーナーの横Gは、スポーツタイヤを履いた実車と同じ 1G 前後が上限（AE86 は 100km/h から約 40m で止まる）。ブレーキとコーナーはタイヤのグリップを分け合う（摩擦円）: ブレーキを強く踏むほど曲がれる力が減り、いっぱいに踏むと曲がれる力は 35% ほどしか残らない（ABS でタイヤはロックしない）。ブレーキを踏みながら深く曲がろうとすると外へふくらむので、まっすぐのうちに減速してから曲がる（`src/sim/vehicle.ts` の `cornerGripShare`）。NPC も同じで、手前でブレーキを済ませてからコーナーに入る。ハンドルは速さに関係なく最大舵角まで切れるが、曲がる力が出るのはタイヤのグリップの限界の角度まで（高速ほど小さい）。それより多く切ると前のタイヤが滑ってアンダーステアになり、曲がる力が少し落ちて（最大 25%）、タイヤが路面をこすって減速し、タイヤが鳴る。限界のちょうど手前で切り続けるのがいちばん速い（`src/sim/vehicle.ts` の `stepVehicle`）。キーボードで押しっぱなしにすると高速では切りすぎになるので、軽く叩いて舵角を調整する。車の動きを大きく変えたときは、タイムアタックの記録・ランキングを前の動きで走った分と分ける（`src/map/courseRevision.ts` の `HANDLING_VERSION`）。速くなるとグリップは少しだけ増える（ふつうは 8%）。重い GT-R（R32・R34）は低速の横Gが控えめな代わりに高速で20%ほど増え、軽い FD3S・エボは低速から強い。そのためタイトな峠や都心環状線のような首都高では FD3S・エボ、高速コーナーの多いコースでは GT-R が速い。
- 性能として持っているのは、最高速・加速（低速での上限と、車重あたりの出力）・ブレーキ・アクセルを離したときの減速・空気抵抗・ホイールベース（小回り）・最大舵角・ハンドルを切る速さと戻る速さ・コーナーで出せる横G・横滑りの収まりやすさ（グリップ）。重さや駆動方式（FR・FF・4WD）は、これらの数値の組み合わせで表している（重い車は加速・ブレーキ・ハンドルの反応を控えめにするなど）。坂の重力と草地での減速はどの車にも同じようにかかる。
- 当たり判定の大きさはどの車も同じで、見た目（屋根の高さ・窓の形・リアウイング・色）と性能（`src/sim/vehicle.ts` の `VEHICLE_PRESETS`）が違う。見た目は `src/render/carMesh.ts` の `CAR_STYLES`。
- 一人で走るときは車ごとの色、オンラインの部屋では人ごとに割り当てた色になる。

### ライト・クラクション・ミラー・セリフ

- ヘッドライトは `F`（スマホはペダルの上の「ライト」）でつける・消す。朝・夜・雨・霧を選ぶと最初からつく。つけると前のランプが光り、テールランプも明るくなる。部屋の人の車にも反映され、近くの2台までは、その車のライトが前の道を照らす様子も自分の画面に出る。
- NPCと対戦・ライバルとバトルでは、「時間帯・天気」の画面で相手（NPC・ライバル）のライトを「つける」「消す」から選べる。はじめに選ばれているのは、夜と雨・霧なら「つける」、晴れた朝・昼なら「消す」（時間帯・天気を選び直すと、それに合わせた方に戻る）。
- ライトを消している車のランプは、まわりの光で照らされるだけで光らない（夜は暗く見える）。
- クラクションは `G`（スマホは「ホーン」）を押している間だけ鳴る。部屋の人にも、遠いほど小さく聞こえる（160 m より遠いと聞こえない。鳴らしている間に近づく・離れると大きさも変わる）。
- ミラーは設定の「ミラー」で なし／バックミラー／サイドのみ／バック＋サイド を選ぶ（最初はバックミラー）。画面のいちばん上の左右の真ん中に、バックミラーを挟んで左右にサイドミラーを並べる（サイドのみのときは、真ん中を空けて左右に置く）。横向きは左上のボタンと右上の地図を避けて左右対称に、縦向きは横いっぱいに出し、上のボタン・周回・地図はミラーの下へずらす。スマホの速度は下の真ん中（縦向きは左下）に出す。後ろ向きのカメラで小さな画像に描き、左右を反転して貼る（画像の更新は1フレームおき。`src/render/mirrors.ts`）。
- セリフ（エモート）は `E`（スマホは「セリフ」）で言う。言うセリフは設定の「セリフ」で自分で決める（20 文字まで。ブラウザ内に保存。空にすると最初の「俺のRについて来れるか！？」に戻る）。自分の車の上に吹き出しが出て、左に「名前 セリフ」が少しの間残る。部屋にいれば全員に出る（続けて言えるのは 1.5 秒おき）。`src/game/emotes.ts`。

### ライバルとバトル

`B`（☰ メニューの「ライバルとバトル」）で、名前付きのライバルと 1 対 1 で走る。メニューでは 対戦相手 → ルール → コース（最初はライバルの得意なコース）→ 自分の車 → 時間帯・天気（最初は今の時間帯・天気。夜・雨が得意なライバルは夜・雨）の順に選ぶ。

ルールは2つ。

- **横に並んでスタート**: 先にゴールしたほうの勝ち
- **先行後追い（サドンデス方式）**: 先行と後追いに分かれ、後追いは先行の 12m 後ろからスタートして1本（周回コースでも1周）走る。判定はゴールの時点でする。後追いが先行を抜いて先にゴールしたら後追いの勝ち、後追いが先行のゴールから 1秒より遅れたら先行の勝ち。1秒以内に続いてゴールすれば引き分けで、先行と後追いを入れ替えて次の1本へ（決着がつくまで続く）。最初に自分が先行か後追いかを選べる。走っている間は何本目か・差を上に出す（`src/race/suddenDeath.ts`）

横に並ぶルールでは、ゴールの画面にコースを区間（700m くらいずつ、3〜8 区間）に分けたライバルとのタイム差を出す。上から見たコースの地図で、離された区間は赤、速かった区間は緑。いちばん離された区間も書くので、どこを練習すればよいかが分かる。周回コースは、同じ区間の周ごとの差を足す（`src/race/sections.ts`）。

- 強さ（初級〜超上級）は NPC の運転のうまさで、車の性能は変わらない。カーブでタイヤのグリップをどこまで使うか（初級 72%・中級 83%・上級 90%・超上級 100%）、ブレーキをどこまで奥で強く踏むか（66%〜100%）、理想のライン（アウト・イン・アウト）をどれだけなぞるか（初級は道路の中央寄り 40%、上級以上は 100%）、最高速をどこまで出すか（88%〜100%）、後ろから迫られたらインを閉めるか（上級以上）が違う（`src/race/npcDriver.ts` の `NPC_LEVELS`）

- **解放**: はじめに戦えるのは初級のライバルだけ。初級を全員倒す（WIN）と中級、中級も全員倒すと上級、上級も全員倒すと超上級のライバルが解放される。まだのライバルはメニューに LOCK と出て、選ぶと残りの相手が分かる（`src/race/rivals.ts` の `isRivalUnlocked`）
- 星野好造は、コーナーに入るたびに「どりゃー！！」「ふりゃあぁー！」などとかけ声を上げる（ほかのセリフが出ている間は言わない）。ライバルは `src/race/rivals.ts` で追加・変更できる。
- メニューのライバルの写真は、画像を `public/rivals/` に置き、`src/race/rivals.ts` のそのライバルに `photo: 'rivals/takumi.jpg'` のように書くと出る（縦長 3:4 くらいがよい）。書いていないライバルは名前の頭文字の絵になる。
- NPC 対戦とバトルでは、走っている間の順位を名前付きで出し、結果の順位表にも名前を出す（自分はランキング用に入れた名前。未入力なら「あなた」）。

### 時間帯と天気

☰ メニュー（パソコンは Esc）でプレイモードとコースなどを選んだ後の「時間帯・天気」の画面で、朝・昼・夜と普通・雨・霧を選べる（ブラウザ内に保存。`?time=night&weather=rain` のように URL でも指定できる）。

- 朝は空が橙色で日差しが低く、影が長い。夜は暗く、自分の車のヘッドライトが前を照らす。夜にライトを消すと月明かりだけになり、白線もほとんど見えない。
- 雨は空が暗く雨粒が降り、タイヤのグリップ（横G・横滑りの収まりやすさ）が 78%、ブレーキが 80% になる。NPC やライバルも同じ条件で走る。走っている途中で天気を変えると、レースはスタートからやり直しになる。
- 霧は遠くが白くかすみ、70m ほど先までしか見えない。
- 見た目は `src/render/scene.ts`、雨の性能は `src/game/environment.ts`。

### スマホ・タブレット

タッチ操作の画面が出る（パソコンでも画面に触れるか `?touch` を付けると出る）。

- 左半分を左右になぞる: ハンドル（指を置いた場所が中心）
- ☰ メニューの「ハンドル: 傾ける」にすると、スマホをハンドルのように傾けて曲がる（切り替えた時の持ち方がまっすぐ。左半分をタップすると今の持ち方をまっすぐに合わせ直す。iPhone では動きセンサーの許可を求められる）
- 右下のボタン: アクセル／ブレーキ（止まってから押し続けると後退）
- 上のボタン: カメラ切替・☰（メニュー画面。もう一度押すと走りに戻る。やり直し・リセットはメニュー画面の「やり直す」から）。カメラ・ライトなどのボタンは指を置いた瞬間に効くので、アクセルを踏みながら・ハンドルを切りながらでも押せる
- 縦向きで開くと、タイトル画面に横向きをすすめる案内が出る
- 指を離したのにブラウザが知らせてこないことがあるので、指の数が変わるたび・アプリを切り替えたときにペダルを確かめ直し、押しっぱなしにならないようにしている
- ホーム画面に追加すると、アドレスバーなしの全画面で遊べる（iPhone は Safari の共有ボタン →「ホーム画面に追加」。Android はメニューの「全画面で遊ぶ」でも可）。ホーム画面から開いたときは Safari と保存場所が別なので、名前や自己ベストは引き継がれない

URL に `?map=1` を付けると教習所コースから始まる（`?map=0` は小さな街）。`?car=fd3s`（`standard`／`kei`／`ae86` など、車の id）で開始時の車を選べる。`?room=ABCD` は招待リンクで、開くと参加画面が出る。`?debug` を付けると開発者ツールから `window.__game` で状態を触れる。

### オンライン（マルチプレイ）

クライアント権威方式: 各プレイヤーが自分の車を計算して 20 回/秒で位置を送り、サーバー（Cloudflare Workers + Durable Objects）は部屋ごとに中継する。他の人の車は 0.1 秒前の位置を補間して表示し、自分の物理ワールドには動かない車体として置く（ぶつかると自分の車だけが押し返される）。

プレイモードの「オンライン」は1つだけで、部屋に入って一緒に自由に走るのも、部屋のみんなとの対戦も、この中で行う（走っている間の `Esc`・☰ の画面は、オンラインではゲームが止まらないので「メニュー」と呼ぶ）。

部屋にはトップメニューの「オンライン」か、メニュー画面の「部屋に入る」（部屋に入っていないときだけ出る）から入る。部屋コードは前に入った部屋のコードが入った状態で開くので、抜けた後もすぐ入り直せる。部屋コードと招待リンクは、それぞれ横の「コピー」で写せる。入っても選ぶ画面には進まず、部屋のいまのコースをそのまま走る（部屋でエントリー中なら、そのエントリー画面が開く）。コースを変えるときはメニュー画面の「コース・車などを変える」で、部屋の全員がそのコースに移動する（オンライン対戦のエントリー中・対戦中は変えられない）。抜けるときはメニュー画面の「部屋から抜ける」（または部屋に入る画面の「退出する」）。

部屋にいる間は、右上の地図の下に部屋コードと人数（対戦中・エントリー中はその表示）、部屋の人の色の点と「名前 ほかN人」を出す。最大8人でも大きさが変わらない。

#### オンライン対戦

部屋にいる間、メニュー画面の「対戦のエントリーを始める」からコースと時間帯・天気を決めると（決めた人が主催）、部屋の全員にエントリー画面が開き、全員が同じコース・条件に移る。各自が車を選んで「準備OK」か「今回は見送る」にし、主催が「スタート」を押すと準備OK の人で一斉にカウントダウンが始まる。全員が選び終えるのを待つのが基本だが、選んでいる人がいても、準備OK の人がいれば「準備OKのN人でスタート」で始められる（確認が出る。選んでいなかった人は今回は見ているだけ）。

- 何人かがほぼ同時にエントリーを始めても、主催は先にサーバーに届いた1人だけ。後の人の分は捨てて、その人には先の人の対戦をもう一度知らせ、そのエントリー画面を開く（選ぶ画面にいる間に誰かが始めたときも、その画面は閉じてエントリー画面が開く）。
- エントリー中に部屋に来た人・一度見送った人も、車を選んで準備OK にすれば出られる。エントリー画面を閉じても、メニュー画面の「エントリー画面」（スマホは右上の「エントリー」）で開き直せる。

- 並ぶ順は準備OK にした順（2列に互い違い）。カウントダウンの間は車どうしがぶつからない。
- 走っている間は順位を出す（上位3人と、その外にいれば自分。最大8人でもスマホの画面を埋めないように）。順位は、ゴールした人はタイム順、まだの人はコースを進んだ距離の順（各自が自分の進んだ距離を位置と一緒に送る）。地図には他の人の位置も出る。
- 自分がまだ走っている間に他の人がゴールすると、画面の真ん中に「〇〇 がゴール」と順位・タイムが少しの間出る。
- ゴールすると順位表を出し、まだ走っている人がゴールするたびに更新する。全員がゴールすると対戦が終わり、次の対戦を始められる。
- 対戦の間は、やり直しの代わりにメニュー画面の「コースに戻る」（PC は `R`）でいる所のコースの真ん中に戻る。コースは変えられない。途中で抜けることもできる（主催がエントリー中に抜けると対戦ごとやめる）。
- サーバーが管理するのは対戦の進行（エントリー・スタートの合図・ゴールの順とタイム）だけ（`server/src/room.ts`）。タイムは各自の計測をそのまま使う。20 分たっても終わらない対戦は打ち切る。

無料枠を守るための制限:

- 接続できるのはゲームのページ（`https://shuheikomatsuki.github.io`）と手元の `localhost` からだけ。ほかのサイトからの接続は断る。
- 日本国内（Cloudflare が IP から判定）からの接続だけ受け付ける。対象は `server/wrangler.jsonc` の `vars` で変えられる（`"*"` で制限なし）。
- 5 分間車が動いていない人は部屋から外す。つないだまま 15 秒以上参加しない接続も切る。
- タブが裏に回っている間は位置を送らない。
- 最後の 1 人が抜けた部屋は、保存していた値（マップ・対戦の様子）を消す。クラクションは 0.15 秒、セリフは 1.5 秒より短い間隔では中継しない。
- ランキングは、コース（id と形の版。例 `happogahara-1a2b3c4`）と車の組み合わせごとに1つの Durable Object（`server/src/leaderboard.ts`）に、上位 50 件とそのゴースト・操作の記録を保存する。読み書きは `GET`/`POST /boards/<コース>/<車>`、ゴーストと操作の記録は `GET /boards/<コース>/<車>/ghosts/<記録の id>`（`{ ghost, inputs }`）。接続できるページと国の制限は部屋と同じ。

手元で試すとき（`npm run server:dev` は国の制限を外して起動する）:

```sh
npm run server:dev                      # http://127.0.0.1:8787 でサーバーを起動
npm run dev                             # 別のターミナルで
# http://localhost:5173/?server=http://127.0.0.1:8787 を2つのウィンドウで開き、O キーで同じ部屋コードに参加
```

公開の設定（初回のみ）:

1. Cloudflare のダッシュボードで「Workers & Pages」を一度開き、`workers.dev` のサブドメインが作られていることを確認する。
2. 右上のアイコン → My Profile → API Tokens → Create Token → テンプレート「Edit Cloudflare Workers」でトークンを作る。
3. アカウント ID を控える（ダッシュボードのアカウントのホーム、または Workers & Pages の画面の右側に表示）。
4. GitHub のリポジトリ → Settings → Secrets and variables → Actions の **Secrets** に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を登録する。
5. main の CI（Actions → 最新の main の実行 → Re-run all jobs）を実行すると `deploy-server` ジョブがサーバーを公開し、ログに `https://car-game-server.<サブドメイン>.workers.dev` が出る。
6. 同じ画面の **Variables** に `SERVER_URL` としてその URL を登録し、もう一度 CI を実行すると、ゲーム側にサーバーの URL が組み込まれる。

### 構成

| ディレクトリ | 役割 |
|---|---|
| `server/` | マルチプレイの中継サーバー（Cloudflare Workers + Durable Objects） |
| `src/net/` | 通信内容の定義、WebSocket 接続、受信した車の補間 |
| `src/core/` | 固定タイムステップのゲームループ、キーボード・ゲームパッド入力 |
| `src/game/` | マップ1つ分（物理ワールド・車・描画物）の生成と破棄、他のプレイヤーの車、ランキング（`ranking.ts`）、クラクション（`horn.ts`） |
| `src/main.ts` | 起動処理と、それぞれの部品をつなぐところ（レースの開始・終了、オンラインの部屋、毎フレームの更新） |
| `src/audio/` | Web Audio API で合成する効果音（エンジン・スキール・衝突） |
| `src/sim/` | 車両モデル（`vehicle.ts`、描画非依存）、Rapier 物理ワールド、車 |
| `src/race/` | タイムアタックと NPC: コースの抽出と中心線、周回・近道・逆走の判定、ゴースト・リプレイ、自己ベストの保存、レーシングラインと NPC の運転 |
| `src/map/` | マップ定義（`maps.ts`）。タイルマップの解析（`tilemap.ts`）と、中心線で描く道路（`road.ts`）。障害物配置 |
| `src/render/` | Three.js のシーン、マップ・車・標識のメッシュ、カメラ |
| `src/ui/` | HUD（速度・ギア・操作説明・通知）、メニュー（`menu.ts` 画面の流れ、`menuFlows.ts` プレイモードごとの画面とポーズ画面の項目、`settingsItems.ts` 設定の項目、`menuDetails.ts` 右側の説明、`courseInfo.ts` コースの形と高低差、`carStats.ts` 車の性能の棒）、リプレイの画面（`replayPanel.ts`） |

- 車の挙動の調整は `src/sim/vehicle.ts` の `DEFAULT_VEHICLE_PARAMS`。
- マップは `src/map/maps.ts` の文字グリッドを書き換えるだけで変更・追加できる（凡例は `src/map/tilemap.ts`）。標識やカーブのガードレールもここで指定する。
- 中心線で描く道路のマップは、`MapDefinition.road` に直線（`straight`）と円弧（`arc`）の区間を並べて書く（`src/map/road.ts` の `RoadPiece`）。周回の道路は始まりに戻るよう長さを合わせる（合わないとエラーになる）。高さの差の足りない交差もエラーになる。

### 公開

`main` ブランチへ push すると GitHub Actions がビルドし、GitHub Pages（https://shuheikomatsuki.github.io/prefix-d/ ）に公開する。テストは PR で通しておき、main ではビルドしてすぐ公開する（main のテストは公開と並行して走る）。
ビルドは相対パスなので、リポジトリ名を変えても設定はいらない（URL の最後がリポジトリ名になる）。
初回のみ、リポジトリの Settings → Pages → Source を **GitHub Actions** に設定する。
